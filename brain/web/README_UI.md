# 大肥鱼 · 记忆大脑 v2 前端说明（web/）

> v3 星图改版后，默认是「宇宙」主题（cosmos），v2 的彩色星图保留为「经典」主题（classic），见下方「v3 · 宇宙主题」。

纯静态文件，不需要构建或 CDN，three.js 已经放在 `vendor/` 里。
- 由后端 `python -m brain`（默认 8780）托管时，直接打开 `http://127.0.0.1:8780/` 就行。
- 单独用任意静态服务器（如 `python3 -m http.server`）或双击 `index.html` 打开也能看，这时会自动切到**演示数据**。

## 页面一览

| 地址 | 内容 |
|---|---|
| `index.html` | **记忆星图**（3D 星系）＋ 右侧 **⚙ 工作台** |
| `index.html#wb=priv` | 打开星图时直接展开工作台的某个页签（可用 mem/priv/ctx/emo/cont/jobs/logs/bak/set） |
| `index.html?star=<记忆id>` | 打开后直接飞到这颗星 |
| `workbench.html` | 兼容旧入口，自动跳到 `./#wb` |
| `garden/` | **记忆花园**（Rosarium 风格，名册 / 记忆 / 日记 / 小说 / 珍藏 / 便条） |
| `atlas/` | **2D 星图**（平面版，适合低配手机）；`atlas2d.html` 会跳过来 |

三个页面共用 `js/config.js`、`js/api.js` 和 `js/mock.js`，顶栏或菜单里可以互相跳转。

## 数据来源：真实后端 / 演示数据

- 右上角的徽章显示当前用的是 **已连接后端** 还是 **演示数据**，点一下可以切换。
- `api.mode` 默认是 `'auto'`：
  - 先请求 `/api/auth/check`，成功就用真实后端；
  - 连不上就自动用 `js/mock.js` 里的模拟后端（接口和 `API_CONTRACT.md` 一致，可以增删改，刷新后复原）。
- 地址后面加 `?mock=1` 强制用演示数据，加 `?mock=0` 强制连后端。
- 管理员密钥：
  - 第一次连后端会弹出密钥框，也可以在 工作台 › 设置 里修改并测试。
  - 密钥存在 localStorage 的 `dafeiyu_admin_key` 里，请求时以 `Authorization: Bearer <key>` 发送。
  - 密钥框里的「先看演示数据」可以不输密钥直接体验。
- 后端在别的地址时，改 `config.js` 里的 `api.base`，例如 `'http://192.168.1.5:8780'`。

## v3 · 宇宙主题（cosmos，默认）

`config.js` 里的 `theme: 'cosmos'` 是默认主题，参照《记忆星图 2.0》视频做的。

### 外观

- 近黑的背景加淡紫色的雾，灰白色的星系，中间是一直发光的双星核心。
- 星系缓慢自转，盘面是斜着看的。

### 布局：时间 = 半径

- 越新的记忆越靠里，一条记忆就是一颗星。
- 星沿着旋臂分布，大小和亮度只看重要度、清晰度。

### 层级

| 层级 | 包括哪些记忆 | 位置和样子 |
|---|---|---|
| 恒星级 | 本体、钉住的、最重要的 | 贴着核心 |
| 行星级 | 整理过的、重要的 | 有淡淡的轨道 |
| 星星级 | 碎片记忆 | 按时间分布 |

- **灰度边界**是外圈一条灰色虚线。又老又弱的记忆在圈外变灰，标着「约 N 天后遗忘」。这只是显示，不会删除任何记忆。

### 交互

- **点一颗星**
  - 选中的星变金色。
  - 同标签的星连成金色星座，连线逐段画出来，线上有光点流动。
  - 左下角出现电影字幕：标题、日期、标签、正文。
- **空闲 14 秒**会自动漫游，配字幕和旁白。
- **快捷键和按钮**
  - `/` 或右下角「⌕」：搜索
  - `W` 或「⚙ 工作台」：工作台
  - 「◎ 漫游」：开始 / 停止漫游
  - 「◐ 经典」：切回 v2 主题
  - 也可以在地址后面加 `?theme=classic`
  - 经典主题下，用菜单里的「切换到宇宙星图」切回来

### 配置

| 配置块 | 管什么 |
|---|---|
| `cosmos{…}` | 外观、漫游 |
| `cosmos.links{…}` | 动态连线 |
| `tiers{…}` | 层级、时间轴、灰度边界 |

星海生长（`growth{…}`）在两种主题下通用。

详细说明见补丁里的 `星图改版说明.md`。

## 记忆星图（index.html）

- **星系**：双旋臂粒子星系，带金色核心「原意识 · 大肥鱼」和底部青绿极光，会缓慢自转；4 秒没有操作后镜头会自己慢慢环绕。
  - 拖动旋转，滚轮或双指缩放。
- **星海生长**：星系会随记忆数量长大——记忆越多，半径越大、旋臂越多（默认 2 → 6 条）、星尘越密，核心也会略微变大变亮。页面开着时如果新记忆让星系跨过了阈值，旋臂会在约 4 秒内平滑展开，已有的星点慢慢滑到新位置，新星从核心飞出，镜头自动拉远，不会突然跳变。搜索框下方右侧显示「记忆 1234 · 旋臂 4」。
  - 参数在 `js/config.js` 的 `growth`（「星海生长」）里；`growth.enabled: false` 即恢复固定星系。
  - 预览：网址加 `?mockcount=2000`（自动进演示数据，模拟 2000 条记忆）；`?growth=0` / `?growth=1` 临时关 / 开；`?lowend=1` 强制低配星尘上限。
- **星点**：每条记忆是一颗星。
  - 颜色表示类型，大小表示重要度和被想起的次数；钉住的星带金环。
  - 越久没想起越暗，状态依次是：清晰 → 模糊 → 残影。
  - 菱形星是花园里的内容（梦、心痕、日记、小说……）。
- **人格星座**：其他人格（如 年年 / 炽 / 淘淘 / 全家共享）在星系外围形成各自的小星座。
- **搜索**：顶部整条搜索框，边输入边出结果；回车或点结果会**飞到**那颗星，不匹配的星会变暗。
- **玻璃卡片**：点任意星，右下角弹出卡片，显示摘要、类型、可见范围和关联。卡片上的按钮可以：
  - 「详情」：打开右侧详情面板，含全文、标签、关联记忆、被想起记录；
  - 「编辑」：直接在工作台里打开这条记忆。
- **回忆脉冲**：后端每次召回、联想、真正用到某条记忆，那颗星就会闪一下，并从核心射出一道光。左下角会实时滚动「召回 / 心流牵出 / 自发想起 / 真用到」。
  - 菜单里的「演示脉冲」可以手动触发一次。
- **思考动画**：大脑每想起一件事，光点从中央双星核心出发 → 飞到焦点记忆（这颗星亮起）→ 沿连线发散到几颗相关的星 → 再收回焦点星 → 回到核心（核心轻轻一跳），路径连线边走边画、走完淡出。
  - 真实模式由后端 `/activate`（以及 `/recall`）的召回驱动，前端轮询 `GET /api/think`（只有记忆 id，按隐私过滤）；没有真实召回时偶尔随机「走神」一次；演示数据模式会自己模拟召回。
  - 菜单「✺ 演示一次思考」可以手动触发；参数在 `js/config.js` 的 `think`（「思考动画」）里，`think.enabled: false` 即关闭。详见根目录《思考动画说明.md》。
- **筛选**：按类型组、人格、可见范围、时间筛选。
- **列表**：所有星的列表，可以按 日期 / 重要度 / 快遗忘 / 想起次数 排序，点一行就飞过去。
- 快捷键：`W` 打开或关闭工作台，`/` 聚焦搜索，`Esc` 关闭面板。

## 工作台（⚙，右侧滑出）

工作台打开时，星图会自动往左让出位置；选中的记忆仍然在可见区域中间，**在工作台里点一条记忆，星图就会飞到它**。

1. **记忆**
   - 统计数字；按 关键词 / 类型 / 人格 / 可见范围 / 状态 / 有效-已替换-已归档 / 来源会话 筛选和排序，带分页。
   - 编辑器可以改：正文、类型、重要度（★1–5）、可见范围（继承 / 私密 / 限定 / 公开）、人格、标签、来源会话、钉住。
   - 操作按钮：
     - **保存**
     - **替换为新版本**（supersede，旧版保留成历史链）
     - **强化**
     - **在星图里看**
     - **遗忘（归档）/ 恢复**
     - **彻底删除**
     - **新建记忆**
   - 编辑器下面还显示：关联记忆（点了就飞过去）、审计日志、替换链。
2. **隐私**（privacy.json 可视化编辑）
   - 私聊列表：每个 QQ 可以设成 私密 / 限定 / 公开，也可以新增私密 QQ。
   - 群聊：可见策略和 can_see。
   - 隐私守卫开关和放行短语。
   - 原始 JSON 编辑器；改完点保存，写回后端（PUT）。
   - 「隐私检查」：输入一句话，看在某个会话里会不会被拦。
3. **上下文预览**
   - 选择会话、人格、是否新会话，再输入一条用户消息，就能看到实际会注入给模型的内容：
     - 每段 system/记忆 的 **token 数和字数**，加上 token 占比条；
     - 召回了哪些记忆（点了飞到星图）；
     - 调试信息。
4. **情绪 · 18+**（这部分**保留**，没有删）
   - 可选看最近几小时，并显示各模块开关状态。
   - **情绪**：各维度当前值的柱状图和历史曲线，可以手动 ±10，下面列出最近的情绪事件。
   - **激素**：多巴胺、催产素、皮质醇、血清素等，柱状图带基线，另有曲线。
   - **身体 18+**（粉色区域）：身体状态柱、身体痕迹、曲线，还有测试身体事件的按钮。
   - **欲望 18+**：欲望曲线和欲望条目，可以直接回复。
   - **梦**：最近的梦和梦的素材，点了飞到对应记忆。
5. **延续性**
   - 新会话开场文本预览。
   - 未完成事项：关闭、删除、新增。
   - 便条：回复、删除、新增。
   - 心痕：新增、删除。
   - 交接：生成、删除。
6. **整理 · 做梦**：每个任务一张卡片，点「运行」立即执行并显示输出。任务包括：
   - consolidate（整理）、reflect（反思）、dream（做梦）
   - review、links、cognition、settle、verify、spill_index
7. **日志**：可以按关键词和级别筛选，每 3 秒自动刷新。
8. **备份**：
   - 查看备份列表，立即备份，校验，下载。
   - 恢复（恢复前会二次确认）。
9. **设置**
   - 管理员密钥：保存、测试连接。
   - 数据来源跳转链接。
   - 人格列表。
   - 后端 settings JSON 编辑；需要重启才生效的项会标出来。

## 记忆花园（garden/）与 2D 星图（atlas/）

- **花园**：月下花名册（每个人格一张卡）、他（主人）现在的状态、留给你的便条，以及记忆 / 日记 / 小说 / 珍藏的浏览。
  - 数据接口是 `/api/view/*`，跟星图共用同一把密钥。
  - 背景图是 `garden/garden.jpg`，样式在 `garden/styles.css` 和 `garden/glass.css`。
- **2D 星图**：Canvas 平面星图，带人格切换、类型筛选、搜索和图例，数据来自 `/api/atlas`。

## 想调 UI，改哪里？——`js/config.js`

所有常用参数都集中在这个文件里，每一项都有中文注释。改完刷新页面就能看到效果。

| 想改的 | 配置项 |
|---|---|
| 连哪个后端 / 默认模式 / 轮询频率 | `api.mode`、`api.base`、`api.pulsePollMs`、`api.timeoutMs` |
| 记忆类型的名字和颜色 | `kinds`（记忆）、`itemTypes`（花园内容）、`typeGroups`（筛选分组） |
| 关联线的名字和颜色 | `linkKinds` |
| 状态 / 可见范围的文字和颜色 | `states`、`scopes`、`scopeColors` |
| 星系形状 | `galaxy.arms` 旋臂数、`radius` 半径、`armTwist` 缠绕程度（`growth.enabled` 为 true 时旋臂数和半径由「星海生长」决定） |
| 星海生长（星系随记忆长大） | `growth.enabled` 总开关、`armSteps` 旋臂阈值、`maxArms`、`radiusMin`/`radiusMax`/`radiusFullAt`/`radiusCurve`/`radiusLogK` 半径曲线、`dustBase`/`dustPerMemory`/`dustMax`/`dustMaxLow`/`lowEnd` 星尘、`coreGrow`/`coreBright` 核心、`animSeconds` 动画时长、`cameraFollow`、`refreshSeconds`、`hud`。详见 `星海生长说明.md` |
| 星系密度和亮度 | `dustCount` 粒子数（**卡的话降到 40000**；开了星海生长则改 `growth.dustMax`）、`dustSize`、`dustOpacity`、`bgStars` 背景星 |
| 核心光晕 | `coreSize`、`bulgeSize`、`coreColor` |
| 极光和天空 | `auroraStrength`、`skyTop` |
| 转速 | `rotateSpeed`（自转）、`idleOrbitSpeed`（空闲环绕） |
| 最亮的星有几颗 | `galaxy.heroCount`、`star.heroSize` |
| 星点大小 / 亮度 | `star.baseSize`、`pinnedSize`、`importanceBoost`、`minBright`、`twinkle` |
| 搜索时不匹配星的亮度 | `star.dimUnmatched` |
| 关联线浓淡 | `star.linkAlpha`、`selLinkMax` |
| 镜头 | `camera.fov`、`distance`（初始远近）、`theta`/`phi`（初始角度）、`minDist`/`maxDist`、`flyDistance`（飞到星时离多近）、`flyEase`（飞行速度） |
| 回忆脉冲 | `pulse.flareDecay`、`flareGain`、`beadSpeed`、`beadSize`、`fromCore`、`kindColors`、`kindLabels` |
| 面板尺寸 / 主题色 | `ui.cardWidth` 卡片宽、`ui.sheetWidth` 详情宽、`ui.workbenchWidth` 工作台宽、`ui.gold`/`ink`/`mute`/`teal`、`ui.glassBlur`、`ui.toastMs` |
| 情绪 / 激素 / 18+ 身体曲线颜色和名字 | `charts.emotion`、`charts.hormones`、`charts.body`、`charts.bodyLabels` |

更深一点的改动：
- 星图样式（卡片、搜索框、详情、列表）：`css/app.css`
- 工作台样式（包括 18+ 粉色区 `.adult`）：`css/workbench.css`
- 宇宙主题样式（字幕、右下角按钮、灰度标签等，都在 `body.cosmos` 下）：`css/cosmos.css`
- 星系渲染和着色器（天空 / 极光 shader）：`js/starmap.js`
- 工作台各页签：`js/workbench.js`，每个页签是一个 `pane_xxx` 函数
- 曲线图组件：`js/charts.js`
- 演示数据：`js/mock-data.js`；模拟接口：`js/mock.js`
