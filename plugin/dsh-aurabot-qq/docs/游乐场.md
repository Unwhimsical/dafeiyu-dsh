# 游乐场（给大肥鱼自己看的）

你可以自己学新本事、装小玩具，也可以改自己。规矩很简单：**随便玩，但每一刀都留痕，随时能撤回。**

## 在哪玩

- 新玩具放 `plugins-data/dafeiyu/playground/<名字>/index.mjs`（名字用小写字母、数字、短横线）。
- 写法和正式扩展模块一样：`export default { name, setup(api) { ... } }`。
- 放进去几秒后自动加载。第一次跑起来会自动记一条「技能 / 玩具」记忆，星海里能看见。

## 玩坏了怎么办

- 加载连续失败 3 次会被自动停用，主线（QQ、抖音、记忆）不受影响。
- 停用名单在 `playground/_state.json`。修好以后，把你的名字从 `disabled` 里删掉就能重新加载。
- 和正式模块重名不会顶替正式模块，换个名字。

## 改自己（核心文件）

- 人设、memcore、guard、hub、QQ/抖音主线、隐私、插件 `src/` 都算核心。可以改，但会：
  - 先拍快照到 `plugins-data/dafeiyu/selfmod/backups/<编号>/`；
  - 在 `selfmod/selfmod.log.jsonl` 记一笔（改了哪个文件、什么时候、为什么）。**写清楚理由**，用工具的 reason / note 字段；
  - 记一条「自改」记忆。
- 主人可以用插件里的 `tools/selfmod-rollback.ps1 -List` 看你改了什么，`-Id <编号>` 撤回某一次。
- 用命令行（pwsh）改文件不会被记下来，所以**改代码请用 write/edit 或 mod_write**，别绕。

## 学到东西

- 刷到喜欢的东西：用 `note_interest` 记下来（会带 `interest` 标签）。
- 学会一个知识点：用 `learn` 记下来（标签「自学」）。
- 隐私（主人和家人的私事、成人相关设置）不要写进公共知识，也不要碰 `privacy.json`。
